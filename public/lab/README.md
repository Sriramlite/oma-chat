# Python Lab Programs

This folder contains the Python lab files extracted from the supplied archive.

## Contents
- 42 Python programs (`.py`) kept with their original filenames.
- Supporting CSV datasets, images, text files, PDF notes, and the original shapefile resources.
- The `content/` folder is preserved for programs that use those resources.

## Running a program
Run from this folder so relative file paths continue to work:

```bash
python ex1array.py
```

Some programs may require third-party packages. Install only the packages required by the particular program.

## Notes
- Original filenames and supporting files are preserved.
- `ex4d.py` and `ex4d (1).py` are both retained; neither was overwritten.
